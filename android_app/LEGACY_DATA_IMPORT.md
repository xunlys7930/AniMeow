# 原版 AniMeow 数据迁移

原生版包名为 `com.animeow.app`，原版包名不同不会影响迁移。导入器读取用户选择的原版文件，不尝试访问另一个应用的私有目录。

## 推荐流程

1. 在原版进入“数据与管理 → 导出备份 (Zip)”。
2. 得到 `AniMeow_backup_*.zip` 后，将文件保存到手机可选择的位置。
3. 在原生版进入“我的 → 导入原版数据”。
4. 选择 ZIP，查看数据库版本及各类记录数量。
5. 阅读警告并确认导入。
6. 成功页记录自动恢复点位置；返回资料库检查作品、进度、封面、角色和系列。

也可直接选择 `anime_tracker_v5.db`。直接数据库不含 `covers/`，因此只能迁移远程封面 URL，不能迁移原版本地封面；优先使用 ZIP。

## 兼容范围

已声明兼容原版 SQLite v1–19。读取器按实际存在的表和列工作，不要求旧版本拥有新表。

迁移内容：

- 作品标题、类型、本地/远程封面、状态、评分、等级评价、趣味评分和文字评价。
- 已看/总集数、TV/SP 集数、开播日期、制作公司、开始/完成日期及每周提醒。
- 自定义状态、系列、作品标签和全部有效关联。
- 观看记录。
- 角色资料、角色评分与评价、作品关联、角色标签和角色关系。
- 角色组、角色组成员/作品、社区 ID、分享码、来源和公开状态。
- AI 分析历史和统计 JSON。
- ZIP 中任意层级 `covers/` 目录下的本地封面。

逐版本结构见 [LEGACY_COMPATIBILITY_MATRIX.md](LEGACY_COMPATIBILITY_MATRIX.md)。

## 预检与确认

选择文件后只执行只读操作：

- 复制到应用缓存中的隔离暂存目录。
- 判断 ZIP 或 SQLite 文件头。
- 对 SQLite 执行 `PRAGMA quick_check(1)`。
- 读取 `PRAGMA user_version`、已知表和现有列。
- 统计作品、系列、标签、观看记录、角色、角色组和封面。
- 对高于 v19 的数据库显示未知字段警告。

预检不会修改当前资料库。关闭确认页会删除暂存文件。

## 确认后的安全流程

1. 先导出当前原生资料库、配置、封面和品牌资源，创建 `before_legacy_import` 完整恢复点。
2. 将原版封面复制到新的独立目录；限制单文件、总大小和 ZIP 条目数。
3. 重写原版绝对路径、Windows 路径、`file://` 路径和 `covers/...` 相对路径。
4. 在单一 Room 事务内替换资料库；任何插入失败均回滚。
5. 重建所有提醒任务。
6. 成功后清理旧的迁移封面目录和暂存目录。

导入语义是“用原版备份替换当前资料库”，不是与当前资料库合并。需要合并两个原生备份时，应使用原生云同步的非破坏合并能力。

## 数据规范化

- 空标题/系列/角色/角色组获得可识别的占位名称。
- 空状态归为“未看”；历史乱码默认状态会修复。
- “看完”且总集数有效时，已看集数补齐到总集数。
- 负数集数归零。
- 数字作品评分兼容 0–10 和旧内部 0–100 两种存储，最终限制在 0.1–10.0。
- 合法等级评分优先于同一行的数字评分。
- 角色评分限制为 1–10，关系强度限制为 1–5。
- 无效系列外键转为空。
- 指向不存在作品、标签、角色或角色组的关联记录被丢弃。
- 角色自关联、孤立关系及同一角色对的反向重复关系被丢弃。
- HTTPS/HTTP/content/resource/data URI 保持原值，不被当作本地封面改写。

## ZIP 安全限制

- 限制源文件、数据库、单张封面、封面总量和 ZIP 条目数量。
- 规范化斜杠并阻止 `../`、绝对路径等路径穿越。
- 只把 `.db` 作为数据库候选；精确名 `anime_tracker_v5.db` 优先。
- 非图片内容即使位于 `covers/` 也只作为文件复制，后续图片加载失败不会破坏数据库事务。

## 原版备份无法提供的内容

原版 ZIP 实际只包含 SQLite 数据库和 `covers/`。以下数据不在原版备份内，无法凭空恢复：

- Flutter SharedPreferences 中的主题、首页布局和交互偏好。
- 原版的临时缓存和登录会话。
- 独立诊断数据库或日志文件。
- 未被原版 ZIP 收集的外部文件。

原生版会保留当前外观、自定义配置档案和账号设置；不会把原版诊断日志导入。

## 验证样本

运行：

```powershell
py -3 scripts/generate_legacy_v19_fixture.py
```

输出位于 `test-fixtures/`：

- `legacy_v19_full.db`
- `legacy_v19_full.zip`

ZIP 包含 3 部作品、1 个系列、作品标签、观看记录、3 个角色、关系、角色标签、角色组、分析历史、提醒和 5 张本地封面，并故意加入越界值和孤立关联。详细预期见 [test-fixtures/README.md](test-fixtures/README.md)。

## 恢复

若导入结果不符合预期：

1. 进入“我的 → 云账号与设备备份”。
2. 找到导入前自动创建的 `before_legacy_import` 恢复点。
3. 预检后执行完整恢复。

恢复点包含导入前的数据库、配置档案、DataStore 设置、本地封面和品牌资源。
