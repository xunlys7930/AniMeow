# AniMeow 发布前手动测试方案

本方案用于自动化测试和 APK 构建通过后的最终真机验收。执行者应记录设备、Android 版本、MIUI/HyperOS 版本、APK 哈希、实际结果和截图。`P0` 失败必须停止发布，`P1` 失败必须修复或明确延期，`P2` 为体验问题。

## 1. 测试准备

### 1.1 APK

- 当前本地验收包：`%USERPROFILE%\Desktop\总\v2.0.5\AniMeow2.0.5.apk`；由 `scripts\build_android.bat package` 生成，当前使用 Android Debug 证书签名，仅用于本地测试。
- Release 未签名中间产物：`app/build/outputs/apk/release/app-release-unsigned.apk`；公开发布验收前必须通过 `ANIMEOW_KEYSTORE_*` 环境变量改用长期保存的私有 keystore，并重新生成同名发布包。
- 记录：版本名、versionCode、SHA-256、签名证书 SHA-256。
- 当前自动化基线、最终测试包哈希、签名和权限审计见 [FINAL_VERIFICATION.md](FINAL_VERIFICATION.md)。

### 1.2 设备矩阵

至少覆盖：

| 设备 | 必须 | 重点 |
|---|---:|---|
| Android 8 / API 26 模拟器或真机 | 是 | 最低版本、通知通道、文件选择、安装 |
| Android 12 / API 31 | 是 | 精确闹钟权限、系统备份规则 |
| Android 13 / API 33 | 是 | 通知运行时权限 |
| Android 14 或 15 / API 34–35 | 是 | 后台启动限制、文件 URI、返回手势 |
| Android 16 / API 36 | 是 | 目标 SDK、边到边、预测返回 |
| MIUI/HyperOS 真机 | 是 | 默认 MIUIX 体验、后台/自启动、图标切换 |
| 7–11 英寸平板或可调整模拟器 | 是 | Navigation Rail、双栏和横屏 |

每个主要流程至少再测一次：系统深色、应用字体 1.4 倍、显示大小放大、横屏。

### 1.3 测试资料

- `test-fixtures/legacy_v19_full.zip`
- `test-fixtures/legacy_v19_full.db`
- 一张竖图、一张横图、一张超长图名图片。
- 一份有效 Bangumi 用户收藏地址或用户名。
- 一份包含新增、重复和异常行的 CSV/XLSX。
- 可选测试云端：普通账号、两个设备 ID、至少一个远端备份。
- 可选更新服务器：提供与当前包名和签名一致、versionCode 更高的 Debug APK。

### 1.4 初始状态

分别执行：

- 全新安装，无任何权限。
- 已有资料升级安装，不清除数据。
- Debug 与 Release 并存。
- 云端配置为空。
- 云端配置有效。

## 2. 安装、启动与导航

### APP-001 `P0` 全新安装

1. 卸载目标包后安装 APK。
2. 从默认启动图标打开。

预期：安装成功；无旧存储权限弹窗；启动无白屏、闪退或重复 Activity；默认进入 MIUIX 风格追番页。

### APP-002 `P0` 冷启动与热启动

1. 强制停止后启动。
2. 切到后台 30 秒再返回。
3. 连续点击桌面图标和通知入口。

预期：只保留一个主任务；状态和滚动位置合理；不会叠出多个首页。

### APP-003 `P1` 主导航自适应

1. 手机竖屏逐一进入追番、发现、日历、社区、统计、我的。
2. 横屏和平板重复。

预期：手机使用底栏，宽屏使用 Navigation Rail；内容不被系统栏遮挡；返回顺序正确；可见主入口始终为 3–5 项。

### APP-004 `P1` 启动落点与导航定制

1. 修改导航顺序，启用社区并隐藏其他可选入口，尝试把可见入口减少到 2 项或增加到 6 项。
2. 选择“我的”为启动页，强制停止并重启。

预期：顺序和显隐持久化；追番/我的无法隐藏；系统拒绝少于 3 项或多于 5 项；社区可作为主导航入口；应用从设定页面启动。

### APP-005 `P1` 深色、动态色与系统切换

切换浅色、深色、跟随系统及动态色；再切换系统主题。

预期：文字对比度正常，弹窗/状态栏/导航栏颜色一致，无不可读色块。

### APP-006 `P0` 外部分享与深链接只预览

1. 把有效角色组分享码复制到剪贴板后返回应用。
2. 从其他应用以 `ACTION_SEND text/plain` 分享同一分享码或 `animeow://` 角色组链接。
3. 从浏览器或 ADB 打开有效角色组深链接、已有作品详情深链接、畸形分享码、超长文本和不支持的 scheme。
4. 对有效角色组请求分别选择“忽略”和“查看预览”，在预览页不点击导入即返回。

预期：只有严格合法的输入才出现确认；剪贴板、文本分享和角色组深链接不会自动联网导入或修改资料库；“查看预览”只加载群组与本机差异，仍需再次明确点击导入；忽略或返回后资料计数不变；作品深链接只打开已有详情；畸形输入被忽略且不崩溃。

### APP-007 `P0` 新版与经典版自由切换

1. 首次启动分别选择现代新版和经典旧版。
2. 从“我的 → 整体风格与界面版本”来回切换至少 3 次。
3. 逐一检查追番、发现、日历、作品详情、编辑器和“我的”，并重启应用。

预期：两套前端均完整保留且功能数据一致；选择持久化；切换不删除资料、不重置页面设置、不叠加重复设置按钮。经典发现和经典日历右上角分别只有清晰可用的专属定制入口。

### APP-008 `P1` 可选预测性返回手势

1. 在“我的”开启预测性返回，从发现、日历和“我的”缓慢执行边缘返回并中途取消，再完整提交。
2. 进入详情、编辑器、设置和反馈池重复返回。
3. 关闭开关后重复以上操作并重启应用。

预期：开启时主导航页面跟随手势平移/缩放，取消不换页，提交返回追番；子页面按导航栈返回。关闭后使用传统返回行为；开关持久化且不与编辑器未保存确认冲突。

## 3. 资料库核心流程

### LIB-001 `P0` 新增作品

1. 手动新增动画，填写标题、状态、评分、进度、TV/SP、日期、制作公司、评价、标签、系列和提醒。
2. 保存并重启应用。

预期：全部字段持久化；详情、首页、日历和统计同步显示。

### LIB-002 `P0` 编辑与未保存返回

1. 修改已有作品后执行系统返回手势。
2. 分别测试“询问”“自动保存”“直接放弃”退出行为。

预期：询问模式出现确认；自动保存完成后返回详情；放弃不写入；保存中不能重复退出。

### LIB-003 `P0` 打卡、撤销与完成联动

1. 对总集数为 3 的作品连续 `+1`。
2. 撤销最近一次。
3. 到达总集数。

预期：进度、观看记录、统计和日历同步；不超过总集数；启用自动完成时状态切到配置的完成状态。

### LIB-004 `P1` 五种首页布局

逐一切换智能聚合、卡片流、海报墙、紧凑索引、推荐宫格。

预期：同一资料在各布局可打开和长按；切换无闪退；大列表滚动稳定。

### LIB-005 `P1` 封面与信息定制

1. 切换 2:3、16:9、1:1。
2. 海报墙双指缩放 2–6 列。
3. 切换标题位置并关闭标题、状态、评分、进度。
4. 切换角标和评分图标。

预期：所有布局遵守配置；隐藏标题后卡片仍可点击；列数不越界；重启后保持。

### LIB-006 `P1` 筛选、搜索与排序

组合测试标题搜索、状态、作品类型、年份、标签、升降序和清除筛选。

预期：结果数量正确；无结果状态明确；清除后恢复全部；设置记忆符合预期。

### LIB-007 `P0` 多选批处理

多选动画和系列成员，执行批量状态、加/移除标签、联网封面和移入回收站。

预期：只修改选中记录；操作结束退出多选；错误有提示且不会部分破坏关联。

### LIB-008 `P0` 回收站

删除带标签、观看记录、角色和提醒的作品，再恢复；随后测试永久删除。

预期：软删除后首页消失、提醒取消；恢复后关联和提醒重建；永久删除不可恢复且无孤立记录。

### LIB-009 `P1` 查重合并

创建标题相同、外部 ID 相同和近似标题记录，扫描并合并。

预期：保留选择的主记录；标签、观看记录、角色、系列及非空资料正确合并；操作可从恢复点回退。

## 4. 封面、系列、标签和状态

### ORG-001 `P0` 本地封面

选择图片，调整焦点和缩放，保存后全屏查看并重启。

预期：无需媒体存储权限；裁剪结果正确；文件在应用私有目录；旋转和缩放查看正常。

### ORG-002 `P1` 系列管理

创建系列、添加/移出作品、选择自定义/成员封面、排序、改列数和批量操作。

预期：首页聚合和系列详情一致；系列删除不会误删作品。

### ORG-003 `P1` 标签索引

创建/重命名/改色/删除标签，从标签索引打开作品列表。

预期：计数正确；删除标签只删除关联；筛选结果实时更新。

### ORG-004 `P1` 自定义状态

新增、排序、改色、重命名和删除状态。

预期：作品状态迁移策略明确；首页筛选、编辑器和统计同步。

## 5. 发现与导入

### NET-001 `P0` 未配置云端的降级

使用 `CLOUD_API_BASE`、`API_TOKEN` 均为空的构建，进入云账号、角色社区、AI、服务器资料库和检查更新。

预期：显示明确未配置说明；本地资料、备份、Bangumi/AniList 能力不受影响；无无限加载。

### NET-002 `P1` Bangumi 数据源策略

逐一测试自动、官方优先、代理优先、仅官方、仅代理，以及封面代理开关。

预期：来源标签和警告正确；单一来源失败时错误可重试；代理地址可恢复默认。

### NET-003 `P1` 搜索、推荐、排行榜和筛选

测试动画/书籍、关键词、年份、季度、类型、标签、最低评分和排序，并在 Bangumi、AniList、服务器、推荐、排行之间切换。准备日期边界数据，验证 2026 冬季包含 2025-12-25 和 2026-03-24、不包含 2026-03-25；清空关键词后选择书籍/漫画推荐。

预期：所有来源均只保留符合条件的结果；冬季服务器查询覆盖目标年与上一年且季度边界与原版一致；书籍/漫画不会请求或混入动画周历；切换来源不会混入被禁用来源；详情字段完整。

### NET-004 `P0` 联网导入与重复处理

导入新作品，再次导入相同外部 ID；另建同标题不同 ID 记录。

预期：精确重复打开已有记录；疑似重复允许打开已有或仍然添加；标签和外部 ID 保存。

### NET-005 `P1` trace.moe

上传截图并打开候选，检查相似度、集数和时间点，完成导入。

预期：文件读取正常；失败可重试；候选与 AniList 补全组合正确。

### NET-006 `P0` Bangumi 收藏批量导入

执行预览、选择状态映射、导入及重复导入。

预期：数量与预览一致；重复不无限新增；错误条目单独报告。

### NET-007 `P0` CSV/XLSX

导出当前资料，检查表头与中文；再导入含新纪录、重复、空标题和异常数值的文件。

预期：导出可由 Excel 打开；导入先预览；异常行报告且不破坏有效行。

## 6. 日历、通知与提醒

### REM-001 `P0` 通知权限

Android 13+ 首次拒绝通知，再从系统设置允许；发送测试通知。

预期：拒绝时不崩溃且有说明；允许后测试通知出现；Android 8–12 不请求不存在的运行时权限。

### REM-002 `P0` 精确闹钟允许

Android 12+ 允许“闹钟和提醒”，创建未来几分钟的提醒并同步。

预期：状态显示“准时闹钟”；到点只出现一条通知。

### REM-003 `P0` 精确闹钟拒绝/撤销

拒绝或撤销精确闹钟权限，重新同步；保留应用至少一个调度周期的验证环境。

预期：状态显示后台调度；WorkManager 安全网仍存在；不会因权限异常崩溃或重复通知。

### REM-004 `P0` 通知深链

在应用前台、后台和被系统杀死三种状态点击作品提醒。

预期：打开正确作品详情；任务栈只有一个首页；返回回到合理页面。

### REM-005 `P1` 系统事件重建

创建提醒后依次测试重启、修改时间、修改时区和覆盖安装新版 APK。

预期：提醒仍在；星期/时间按新时区计算；无重复任务。

### REM-006 `P1` 日历定制与补全

切换月/周/议程、标记样式、模块、筛选和封面；对缺失日期执行联网补全。

预期：事件数量一致；补全只修改选定字段；关闭模块不删除数据。

### REM-007 `P0` 长列表触底稳定性

在日历定制、待补日期、发现筛选/数据源/页面定制、追番排序/标签/组合筛选/首页定制、编辑器定制和统计定制中反复快速滚动到底部并继续上划，再从底部回到顶部；同时测试系统字体 1.4 倍和横屏。

预期：内容可稳定停在边界，画面不发生上下抽搐、回弹循环或面板位移；操作项仍可点击，系统返回可正常关闭面板。

## 7. 统计、Tier List 与 AI

### ANA-001 `P1` 统计正确性

使用已知 3–5 部动画及书籍/漫画数据核对总数、类型计数、状态、评分、标签、观看时长、连续打卡和活动计数。分别点击状态与标签分布，在下钻页搜索并切换最近、标题、评分和进度排序。

预期：动画数与书籍/漫画数之和等于作品总数；计数和百分比可人工复算；下钻集合与所点状态/标签严格一致，搜索和排序正确，返回时保持统计页状态；空资料库不出现除零或 NaN。

### ANA-002 `P1` 统计定制

为自定义状态和标签设置易辨认颜色，再切换经典卡片/档案仪表盘布局、统计预设、模块顺序/显隐、密度和图表样式；逐项开关总收录、动画、书籍、已看集数、估算时长、连续打卡与平均评分。

预期：新安装或旧配置升级后连续打卡默认不展示；经典卡片布局保持原有结构，档案仪表盘以紧凑资料卡和分区卡片展示；所有指标开关即时生效并在重启、配置备份恢复后保持，允许全部隐藏且不会留下空白错位。

预期：图表、图例和下钻入口继承自定义颜色；配置实时更新并持久化，转场遵循全局动效等级；隐藏全部可选模块时仍保留可退出入口。

### ANA-003 `P1` Tier List

跨档拖动、改五档名称/标题、切换四套样式并导出分享图。

预期：顺序保存；图片包含正确封面和文字；分享面板可打开。

### ANA-004 `P1` AI 分析

未配置时检查降级；配置后选择模型、编辑提示词、生成分析、查看和删除历史。

预期：发送前统计大小受限；错误不写入伪成功记录；历史可恢复显示。

### COM-001 `P0` 登录边界与官方群

1. 未登录进入“社区”，确认只显示登录引导；直接请求帖子、头像和图片接口。

预期：未登录无法读取任何帖子、头像或图片；登录后只有一个官方群且成员关系正常；普通用户不存在创建群聊入口，服务端也没有普通建群接口。
