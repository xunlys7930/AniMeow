# AniMeow 1.3.7 功能测试清单

适用于 `1.3.7+24` 客户端和可选自建后端。每项记录“通过 / 失败 / 不适用”和测试环境。

## 发布前自动检查

- [ ] `flutter pub get`
- [ ] `flutter analyze --no-fatal-infos`（当前版本无 error/warning；信息级 lint 另行跟踪）
- [ ] `flutter test`
- [ ] Android Release 构建成功，版本为 `1.3.7 (24)`
- [ ] Windows Release 构建成功
- [ ] APK 通过 `zipalign`、签名和安装验证
- [ ] APK Manifest、DEX、权限和资源中没有广告 SDK、广告组件或广告跟踪权限
- [ ] `rg` 扫描未发现 `.env`、token、密码、私钥、数据库、日志和构建产物
- [ ] `cd backend && npm ci && npm run check && npm audit --omit=dev`

## 客户端基础功能

- [ ] 冷启动、热启动、升级安装和首次安装均能进入首页
- [ ] 新增作品：手动填写、Bangumi 搜索、AniList 搜索、封面加载和失败重试
- [ ] 编辑作品：标题、简介、集数、评分、标签、制作公司、播出日期和备注保存后重启仍存在
- [ ] 状态切换：想看 / 在看 / 看完 / 弃坑及自定义状态
- [ ] 首页四种布局切换、排序、筛选、分页和空状态
- [ ] 详情页四种布局、模块显隐、拖拽排序和编辑页/查看页分离
- [ ] 系列聚合、系列详情、角色关联和角色删除范围（仅解除关联 / 永久删除）
- [ ] 追番日历、放送信息、提醒创建 / 修改 / 删除 / 触发
- [ ] 统计图表、评分模式（0–10 / A–D）和颜色自定义
- [ ] 图片裁剪、封面缓存、网络失败占位图和恢复加载
- [ ] Excel 导入、全量备份、恢复、重复导入和异常文件提示
- [ ] 深色 / 浅色主题、字体缩放、横竖屏和 Android 返回键
- [ ] Windows 窗口启动、通知、文件选择和安装 / 卸载后数据保留

## 云端与后端（配置后执行）

- [ ] 未配置 `CLOUD_API_BASE` 时，本地功能可用，云端入口给出明确提示
- [ ] 注册：用户名、密码、确认密码和邀请码校验；邀请码只能使用一次
- [ ] 登录、退出、重启后会话恢复、会话过期和错误密码处理
- [ ] 忘记密码：账号 + 邀请码验证、密码更新和旧会话失效策略
- [ ] 用户只能读取、下载和删除自己的云备份；5 分钟冷却和最多 3 份保留规则生效
- [ ] 反馈提交、列表读取和异常数据库兼容处理
- [ ] 角色群组创建、公开 / 私有、分享码、下载计数和所有者编辑 / 删除权限
- [ ] Bangumi / AniList 代理的超时、无效 ID、上游 429 / 5xx 和错误信息脱敏
- [ ] 检查更新、下载跳转、下载计数和未配置下载地址时的 404
- [ ] AI 分析无 Key、上游失败、重复生成、统计大小限制和并发锁
- [ ] 管理员接口无 token / 错 token 均拒绝；生产环境不存在源码默认密钥

## 无广告回归

- [ ] 首页、详情页、列表、搜索、设置、关于页、更新弹窗无广告位或广告占位
- [ ] 无开屏广告、插屏广告、Banner、激励视频、广告跳转或广告追踪 SDK
- [ ] 离线启动和网络恢复过程中不出现广告请求
- [ ] Android Manifest 无广告相关权限，APK/DEX 无广告 SDK 包名或广告服务注册项
